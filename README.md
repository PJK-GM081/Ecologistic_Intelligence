# Ecologistic_Intelligence
Proyek machine learning yang berfokus pada analisis risiko keterlambatan pengiriman dan estimasi jejak karbon dalam supply chain.  Proyek ini membangun pipeline end-to-end untuk membantu pengambilan keputusan logistik berbasis data, dengan menggabungkan prediksi keterlambatan dan evaluasi dampak lingkungan dalam satu sistem.
